# FlowChart

A simple, lightweight flowchart workspace using HTML, CSS, and Mermaid.

## Structure

- `index.html` — main flowchart page
- `style.css` — UI styling
- `flowchart.md` — editable Mermaid flowchart source

## Run locally

Open `index.html` in a browser.

## Flowchart

The diagram is rendered with Mermaid in the browser.
